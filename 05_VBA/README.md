05 — VBA & Automatisation Excel

Cette section présente mon apprentissage de VBA (Visual Basic for Applications) pour automatiser des tâches dans Excel et développer de petites applications de gestion.

🎯 Objectif

Apprendre à utiliser VBA pour automatiser des traitements, manipuler des données et créer des interfaces permettant à un utilisateur d'interagir avec un fichier Excel.

📚 Contenu
Jour	Thème
J25	Fondamentaux de VBA et automatisation
J26	UserForms et gestion des ventes
💻 Fondamentaux VBA

Les exercices portent notamment sur :

Variables
Types de données
Conditions If...Then...Else
Boucles
Manipulation des cellules
Manipulation des feuilles
Macros
Recherche de données
Calcul et automatisation des KPI
Gestion des erreurs
Exemple d'automatisation

Le projet permet notamment de calculer automatiquement le chiffre d'affaires à partir des données de ventes et de générer des indicateurs de suivi.

🖥️ UserForms

Le Jour 26 permet d'aller plus loin avec la création d'une interface utilisateur dans Excel.

L'application permet notamment de :

Rechercher une vente à partir de son identifiant
Modifier une vente
Supprimer une vente
Interagir avec les données depuis un formulaire
Automatiser la gestion des ventes

Cette approche permet de transformer un simple fichier Excel en une petite application de gestion.

🛠️ Compétences travaillées
Programmation VBA
Automatisation des tâches
Manipulation des objets Excel
Création de macros
Création de UserForms
Gestion des événements
Recherche et modification de données
Suppression de données
Création d'une logique CRUD (Create, Read, Update, Delete)
