03 — Power Query

Cette section présente mon apprentissage de Power Query, un outil d'Excel permettant d'importer, transformer, nettoyer et consolider des données.

🎯 Objectif

Apprendre à construire un processus de préparation des données reproductible, depuis l'importation jusqu'au chargement des données transformées dans Excel.

📚 Contenu
Jour	Thème
J21	Importation, transformation et nettoyage avec Power Query
J22	Consolidation et automatisation des données
🛠️ Compétences travaillées
Importation de données
Transformation des données
Nettoyage des données
Suppression et gestion des erreurs
Modification des types de données
Fusion de tables
Ajout de requêtes
Création de colonnes conditionnelles
Chargement des données dans Excel
Actualisation des requêtes
Automatisation du processus de préparation des données
🔎 Gestion des anomalies

Les exercices incluent plusieurs anomalies volontairement introduites dans les données :

Produit inexistant
Vendeur inexistant
Quantité vide
Date incorrecte
Identifiants contenant des espaces

L'objectif est d'identifier et de traiter ces problèmes avant l'analyse.

📊 Mini-projets

Les exercices pratiques utilisent plusieurs tables liées aux ventes :

Ventes
   │
   ├── Produits
   │
   └── Vendeurs

Les données sont importées, transformées puis combinées afin d'obtenir une base exploitable pour l'analyse.
